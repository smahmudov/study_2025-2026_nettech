# Цели и задачи работы

## Цель лабораторной работы
Изучение принципов настройки адресного пространства IPv4 и IPv6, построение сети с двойным стеком и проверка взаимодействия устройств в среде **GNS3**.

## Задачи
1. Выполнить разбиение IPv4 и IPv6 сетей на подсети.  
2. Настроить адресацию на маршрутизаторах **FRR** и **VyOS**.  
3. Проверить связность между узлами по протоколам **ICMP** и **ICMPv6**.  
4. Проанализировать трафик с помощью **Wireshark**.  
5. Подтвердить корректность работы протоколов **ARP**, **ICMP** и **ICMPv6**.

# Теоретическая часть

## Основные инструменты
* **GNS3** — эмулятор сетевой инфраструктуры.  
* **FRRouting (FRR)** — платформа маршрутизации уровня L3.  
* **VyOS** — дистрибутив Linux с функциями маршрутизатора.  
* **VPCS** — эмулятор конечных узлов.  
* **Wireshark** — анализатор сетевого трафика.

# Разбиение сетей

## IPv4: 172.16.20.0/24
* Разбита на три подсети:  
  * `/25` — 126 узлов  
  * `/26` — 62 узла  
  * `/26` — 62 узла  
* Broadcast-адреса: `172.16.20.127`, `172.16.20.191`, `172.16.20.255`.

## IPv6: 2001:db8:c0de::/48
* Разделена на две подсети `/49` по идентификатору подсети.  
* Вариант деления по Interface ID — два блока `/65`.
